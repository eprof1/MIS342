Assignment Overview

This assignment introduces the instructor-provided Course Agent before students configure a personal Hermes Agent. It is synchronized with Summative01 and emphasizes how people, processes, data, technology, and controls create business value.

Download GenAI01_CourseAgentVerification_Template.txt. Complete and save it as GenAI01_CourseAgentVerification.txt in your GenAI01 assignment folder.

Safety: Use only course-related information. Do not enter passwords, API keys, private information, or another student's work.
Learning Objectives and Course Alignment

Primary course outcomes: 1, 10, 11, and 12.

  • Distinguish a course-controlled agent from a general-purpose AI service.
  • Improve a vague prompt by adding task, context, constraints, and desired output.
  • Verify an AI response against an authoritative course source.
  • Explain why the student remains responsible for learning and submitted work.
Permitted and Prohibited AI Use

Enabled AI tools for this assignment

  • Course-Agent chat for explanation, planning, checklists, and formative assistance.
  • Course materials and authoritative assignment instructions for verification.

Prohibited AI tools and actions

  • Submitting unverified AI output as your own reasoning.
  • Entering credentials, private information, or another student's work.
  • Asking the agent to impersonate you, fabricate evidence, or bypass course requirements.

Approval rule: Keep normal the course agent approval prompts enabled. Review every proposed file write, command, browser action, or configuration change before approving it.

Exercise 1 — Improve a Prompt
  1. Ask the course agent a vague question about Summative01.
  2. Rewrite the prompt to include the assignment, business context, specific task, constraints, and desired output.
  3. Compare the two responses.
  4. Record the prompts and comparison in GenAI01_CourseAgentVerification.txt.
Exercise 2 — Verify a Course Answer
  1. Ask one factual question about the Digital Artifact Notebook or Summative01 instructions.
  2. Locate the relevant authoritative course instruction.
  3. Determine whether the response was correct, incomplete, or unsupported.
  4. Record the source and verification result in the required output file.
