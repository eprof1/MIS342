Digital Artifact Notebook

Course Information

200 points
 

Assignment Overview

Create a Digital Artifact Notebook, a course notebook used to save visible evidence, verification statements, and reflections for Summative assignments in this course.

The introductory tool is Microsoft OneNote through WSU Microsoft 365. The desktop application is the preferred tool.

Business professionals need to document completed work, preserve evidence, explain technology decisions, and submit work in a format another person can review. This notebook gives you a consistent way to organize evidence across courses and in your professional career.

Required Software and Tools

  1. Windows 11
  2. Microsoft OneNote through Microsoft 365 / Office 365. The OneNote desktop application is recommended; the web version is acceptable.
  3. Access to your WSU Microsoft account and OneDrive for Business
  4. A screenshot tool: Windows Snipping Tool, Print Screen, Windows + Shift + S
  5. Ability to print or export a OneNote page as a PDF
  6. D2L access for assignment submission

Help and responsible AI use: If you do not understand how to complete a step, use an AI tool, web search, the WSU Technology Services Knowledge Base, a teaching assistant, a classmate, or the instructor. You are responsible for verifying the accuracy of any help you receive.

Privacy check: Do not include passwords, private messages, student ID numbers, financial information, unrelated browser tabs, or other sensitive personal information in screenshots or evidence.

Learning Objectives

After completing this assignment, you will be able to:

  1. Create and organize a Microsoft OneNote notebook for course work.
  2. Create an Assignments section and a Digital Artifact Notebook page.
  3. Copy the current Digital Artifact Template into the required page.
  4. Capture and insert visible evidence of completed digital work.
  5. Write verification and business or course relevance statements.
  6. Reflect on what you learned and identify help resources when used.
  7. Export or print a OneNote page as a PDF and submit it to D2L.
  8. Apply basic privacy and professionalism standards when documenting digital work.

Assignment Instructions — OneNote

Step 1: Open OneNote

Make sure you can access your WSU account and Microsoft 365 applications. If you cannot access them, contact WSU Technology Services.

Open a browser and navigate to OneNote in Microsoft 365.

Step 2: Create a new notebook

Create a new blank notebook. Name it using this format:

SemesterYearCourse_YourName

Example:

Fa26MIS362_PatPaulson

Use your actual semester, course, and name. This assignment is used in multiple MIS courses, so the course part may vary.

Step 3: Create the assignment structure

  1. Create a section named Assignments.
  2. Create a page named Digital Artifact Notebook.
  3. Use this same section and page pattern for future summative course assignments.
  4. Future assignments are created on separate pages

Step 4: Copy the artifact template

Copy the Current Digital Artifact Template and paste it into your Digital Artifact Notebook page.

The template includes four sections: Task Evidence, Reflection, Final Check, and Submission.

Step 5: Capture task evidence

Use a screenshot tool to capture visible evidence showing:

  1. Your OneNote notebook name.
  2. The Assignments section.
  3. The Digital Artifact Notebook page.
  4. The Digital Artifact Template pasted into the page.

Paste or insert the screenshot into Section 1 — Task Evidence of the template, replacing the placeholder text.

Important: Do not submit only a file icon. The evidence must be visible in the final PDF.

Write a verification statement in your own words. Example:

This artifact verifies that I created a OneNote notebook named 'Fa26MIS362_MyName' with an Assignments section and a Digital Artifact Notebook page containing the artifact template with appropriate evidence.

Complete the business or course relevance sentence. Example:

This matters because I will use this notebook to organize evidence and reflection for future MIS assignments.

Step 6: Reflect on what you learned

Complete Section 2 — Final Reflection. Answer in complete sentences.

Step 7: Complete the final check

Complete Section 3 — Final Check. Each checklist item should be reviewed before exporting the PDF.

Step 8: Save as PDF

Print, export, or save the completed OneNote page as a PDF. Make sure the PDF shows the evidence, verification statement, business or course relevance sentence, reflection, checklist, and submission section.

Use the file name required by your instructor. If no specific file name is given, use:

SemesterYearCourse_YourName_DigitalArtifactNotebook.pdf

Example:

Fa26MIS362_PatPaulson_DigitalArtifactNotebook.pdf

Step 9: Submit to D2L

Upload the PDF file to the D2L assignment folder named Digital Artifact Notebook or the assignment folder specified by your instructor.

Assignment Final Check

  • [  ] The notebook is correctly named using SemesterYearCourse_YourName.
  • [  ] The assignment area exists and is named Assignments.
  • [  ] The required page or note exists and is named Digital Artifact Notebook.
  • [  ] The current Digital Artifact Template is pasted into the page or note.
  • [  ] Task Evidence 1 shows a readable, visible artifact of the notebook structure and template.
  • [  ] The evidence is not just a file icon and will be visible in the final PDF.
  • [  ] The verification statement is written in your own words.
  • [  ] The business or course relevance sentence is completed.
  • [  ] The final reflection section is done using complete sentences.
  • [  ] The privacy check is complete; private information has been removed or avoided.
  • [  ] The final PDF opens correctly and can be reviewed without additional explanation.
