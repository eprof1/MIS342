Assignment Purpose and Learning Outcomes

Formative03 introduced how related normalized tables can be recombined with queries. Summative03 asks you to translate LuckyTire business questions into tested multi-table queries and explain the join/calculation logic.

After completing this assignment, you will be able to:

  1. Inspect relationships in an existing normalized LuckyTire database.
  2. Create a multi-table query using relationship-based joins.
  3. Create and verify calculated fields, criteria, and sorting.
  4. Read and interpret the Access SQL generated by Query Design.
  5. Evaluate whether query results answer the intended business question.

Primary course learning-outcome alignment: CLO 4, with supporting evidence for CLOs 3 and 8.

Questions 1 through 6 require concise answers of no more than 500 characters. The Final Assignment Reflection allows a longer response.

Exercise 1 — Build a Multi-Table Query
  1. Download LuckyTire_Normalized_Summative03.accdb and save a working copy as Summative03_LuckyTire.accdb.
  2. Open the Relationships window and identify the customer-to-sales and tires-to-sales relationships. Do not renormalize the database.
  3. Create a new query in Design View using the customer, sales, and tires tables in the starter database.
  4. Include customer name, invoice/date, tire model/manufacturer or tire type, quantity, and unit price fields using the actual starter field names.
  5. Add a calculated field named ExtendedAmount that multiplies Quantity by UnitPrice.
  6. Save the query as qryCustomerTireSales and run it.

Exercise 2 — Answer a Business Question
  1. Create a copy of qryCustomerTireSales named qrySalesAnalysis.
  2. Add criteria that answer a real LuckyTire question, such as one manufacturer/tire type, a quantity threshold, or a date range that exists in the data.
  3. Sort by a useful field such as customer last name, date, or ExtendedAmount.
  4. Run the query and record the number of returned rows.
  5. Verify at least two returned rows by checking the related source table records.

Exercise 3 — Inspect and Interpret Access SQL
  1. Open qrySalesAnalysis in SQL View.
  2. Identify the SELECT fields, FROM/JOIN portion, WHERE criteria, calculated expression, and ORDER BY clause when present.
  3. Return to Design View, make one small deliberate change to the criteria or sort, and reopen SQL View.
  4. Observe which portion of the SQL changed.
  5. Run the revised query and verify that the result changed in the way you predicted.
