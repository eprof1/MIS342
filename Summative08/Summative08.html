Assignment Purpose and Learning Outcomes

Formative08 introduced Access as a front end to external data. Summative08 requires you to demonstrate and evaluate the difference between local Access data and a MariaDB/MySQL table linked through ODBC.

After completing this assignment, you will be able to:

  1. Link Access to an external relational database through ODBC.
  2. Distinguish local Access tables from linked server tables.
  3. Query and verify data that physically reside outside the Access file.
  4. Compare local and client/server copies of the same small data set.
  5. Evaluate availability, security, and administration tradeoffs of linked data.

Primary course learning-outcome alignment: CLO 9, with supporting evidence for CLOs 8, 10, and 11.

Questions 1 through 6 require concise answers of no more than 500 characters. The Final Assignment Reflection allows a longer response.

Exercise 1 — Link the MariaDB/MySQL Table
  1. Download LuckyTire_Normalized_Summative08.accdb and save a working copy as Summative08_LuckyTire.accdb.
  2. Confirm that you are on the required campus network or Cisco VPN and can reach the instructor-designated database host.
  3. In Access, choose External Data > New Data Source > From Other Sources > ODBC Database.
  4. Choose Link to the data source by creating a linked table and use only the approved 64-bit course ODBC configuration.
  5. Link the instructor-designated LuckyTire table, preferably LuckyTireLocations when configured.
  6. Open the linked table and identify the linked-table icon/indicator. Do not expose credentials in screenshots.

Exercise 3 — Compare Local and Linked Data
  1. Import LuckyTire_Locations.csv as a new local table named tblLocationsLocal.
  2. Keep the ODBC-linked location table linked; do not convert it to a local table.
  3. Compare row counts and at least two field values between tblLocationsLocal and the linked table.
